Why this matters

A scalar score hides cross-task interference. EMHO-Merge looks for an observable condition that explains when the mutated behavior helps and when it hurts. If there is no stable separator, separate specialists can be better.

RHEvolution change: every mutation should persist gained tasks, lost tasks, unchanged tasks, and activation events. A merge should have to beat the null option: keep specialists separate.

Why this matters

RHEvolution can create the same evaluator drift. The diagnostic evaluator should be allowed to evolve, but its measured progress must stay anchored to a slower, independent evaluation lane.

RHEvolution change: track the discrepancy between search-evaluator improvement and anchor-evaluator improvement. Persistent divergence should trigger evaluator audit, not another harness mutation.
