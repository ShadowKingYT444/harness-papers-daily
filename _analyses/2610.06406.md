## What is actually new

The paper introduces the **Evidence-Grounded Behavior Graph (EBG)**. It deterministically converts raw repository or trajectory evidence into source-linked units, behaviors, scopes, and explicit relations. A monitor reads task-oriented views of this graph and can verify findings against original sources.

For RHEvolution, the key idea is evidence preservation before interpretation.

## Mechanism

Each evidence unit keeps a stable ID, original content, and source location. Repository behaviors use Condition-Operation-Result. Trajectory behaviors use Demand-Action-Response. Related behaviors are grouped into scopes and linked with explicit evidence-supported relations.

~~~mermaid
flowchart LR
 A["Raw repository + trace"] --> B["Source-linked evidence"]
 B --> C["Behavior tuples"]
 C --> D["Scopes + relations"]
 D --> E["Task-oriented view"]
 E --> F["Monitor finding"]
 F --> G["Source verification"]
 G --> H["Ownership intervention"]
~~~

## Results that matter

Human double-review agreement is **92.4%** for SpecGAP, **93.6%** for SilentSwap, and **93.0%** for FeedbackTrace.

For GPT-5.6 Sol, EBG changes SpecGAP LF1 from **0.501 to 0.569**, SilentSwap LC from **0.428 to 0.570**, SilentSwap LS from **0.464 to 0.671**, and FeedbackTrace EHR from **0.550 to 0.610**.

In the high-input bin, evidence-localization gains are about **+0.078**, **+0.115**, and **+0.108** on the three corresponding benchmark families. Some individual cells decline, so the gain is not universal.

## Why this matters for RHEvolution

The ownership graph should not consume only free-text evaluator prose. Use:

raw evidence -> behavior graph -> evidence-backed finding -> dependency or intervention test -> ownership graph.

This entry also preserves the useful principle from VISTA: the solver's compact working context and the optimizer's lossless evidence store should be different objects. Context can be compressed. Original traces, tool outputs, file versions, screenshots when relevant, and timestamps should remain retrievable.

EBG is not a causal graph. Do not convert graph connectivity directly into ownership credit.

## What RHEvolution should change

1. Give important trace events and artifacts stable evidence IDs.
2. Require evaluator findings to cite source locations.
3. Keep the behavior graph separate from the ownership graph. Add ownership confidence only after dependency or intervention evidence.
