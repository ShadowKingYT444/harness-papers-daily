## One line
Turns failures in execution traces into scoped harness changes along four design dimensions — verification, retrieval, decomposition, knowledge synthesis — using an "overhypothesis" that recurring failures in a task kind admit shared remedies.

## The problem
Full-episode evaluation is expensive: each harness candidate can cost hundreds of tool calls, and final scores hide where things went wrong. Vestrum bets that the trace — what the agent retrieved, preserved, and assumed before failing — contains a diagnosable, *classifiable* failure, and that failures of a shared kind recur across tasks, so one scoped remedy transfers within the kind.

## How it works
Each epoch: (1) diagnose — an LM reads development traces and localizes failures as *predicates recognizable in other traces* (e.g., "changed shipped code before establishing the invariant"); (2) propose — failures are organized by (task kind × failure class), and the proposer considers four design dimensions: **verification** (what's checked, when), **retrieval** (what information is accessed), **decomposition** (how work is divided), **knowledge synthesis** (what's distilled/recorded); (3) screen — an LM reviewer checks whether the mechanism's condition and content generalize beyond the originating example, plus a lexical leakage lint against task-specific names; (4) evaluate as a bundle — promising mechanisms are composed into a bundle S, evaluated as h+S on development tasks, then pruned to h+S′ if trace analysis shows some mechanisms didn't act or were harmful; (5) admit only if bundle beats the incumbent on the admission criteria (e.g., must fix checks Claude Code fails in every draw, lose no check on another task kind, cost <1.5× per task). A persistent **lessons file** carries successes, failures, and repeated refusals into later epochs. No model is ever trained — frozen task models throughout.

## Key results
- UltraHorizon: 47.6 → 59.8 over GAM; Terminal-Bench 4 Hard: 63.7% → 70.3% of checks passed over Claude Code at 1.03× test cost (8 held-out tasks, none declined); cell-type annotation agreement 67.5% → 77.8% (macro-F1 64.8 → 76.5); gains on LoCoMo and AMA-Bench.
- Beats GEPA configurations on all three memory benchmarks with fewer-or-comparable task-agent evaluations (but higher learning-token use on two).
- A striking empirical pattern: *evidence-grounded verification* helped (17/18 intermediate-step repairs on AMA-Bench), while critics asked to rebuild finished answers broke more than they repaired (9 vs 5 overturns) — verification should be placed where intermediate results get committed.
- Ablation: removing the lessons file drops development gains 16→10 checks; removing failure classes + generalization screening eliminates validation gain.

## How it relates to adaptive decomposition
Vestrum's four dimensions *include* "decomposition" (how work is divided), but that's a dimension the proposer considers when diagnosing a failure — it's not the search mechanism, and the decomposition is never given an independent budget, never evolved in parallel, and never recursively split further. The component structure is not an object of search at all; what evolves is a *bundle of scoped mechanisms* applied to a monolith. There is no agent-discovered decomposition, no splitting of failing pieces, no fusing, and no monolithic revert — the closest analog is the bundle prune step (drop mechanisms that didn't act), which is coarse-grained selection, not adaptive re-decomposition. Useful as a paper that shows verification and scope discipline matter, but the search object remains flat.

## Limits and open questions
The overhypothesis ("recurring failures admit shared remedies") is an inductive bias explicitly acknowledged to have no guarantee — the generalization screen is an LM reviewer, so rigor there is thin. The four dimensions were motivated by pilot experiments where open-ended proposals failed; it's unclear how much the result is "failure classes transfer" vs. "good hand-chosen dimensions + persistent lessons." Test repetitions measure execution variation of frozen harnesses, not independent searches, so we don't know how stable the discovered mechanisms are across runs.
