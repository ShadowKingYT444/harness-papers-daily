## One line
DynaHarness: a dynamic physical harness for robot agents where a slow brain (Qwen3-VL-4B, on demand) proposes capabilities and symbolic arguments, a fast brain (2 Hz) grounds, bounds, monitors and refuses commands — substituting capabilities or requesting replans — under a shared physical execution contract that records evidence, and an offline loop attributes failures to N ordered diagnostic layers, directs targeted revisions of reusable capabilities, and admits them only through paired regression checks.

## The problem
Pretrained VLA policies give useful action priors but not long-horizon manipulation: semantic reasoning runs at a coarser timescale than physical interaction, contact/progress/success arise *between* planning decisions so an explicit authority must govern the running command, and episode-level outcomes give no guidance on which component (planning, grounding, dispatch, capability, verification, recovery) to revise. Embodied harnesses either orchestrate execution without revision, or revise capabilities without localizing which layer failed.

## How it works
(1) **Slow brain** reads an atomic context snapshot (instruction, scene, observation, timestamped history) and returns a structured advisory: a capability m_j from library L (analytic skills, recovery skills, vla_act to a frozen π0.5) plus symbolic arguments — no poses. (2) **Fast brain** (deterministic, 2 Hz) grounds the advisory into a command γ=(m, θ, B, τ): physical parameters, step budget, lease — returning refusal ⊥ with a reason when unresolvable; latches transient completion events between decisions; then continues, invokes recovery, switches capability, or requests a replan. Commands end on local completion/failure, latched verdict, budget exhaustion or lease expiry. (3) **Physical execution contract**: every robot-facing command is grounded (resolves through the execution interface), bounded (budget + lease + 50 Hz safety check), verifiable (ends on recorded status), and attributable (an episode evidence store logs observations, decisions, outcomes, reasons — refusals included, so unresolved commands are distinguished from failed executions). (4) **Offline self-evolution**: failure attribution picks the first matching label among N ordered layers (infrastructure, context, planning, grounding, dispatch, capability execution, verification, recovery); the attributed signature directs a targeted capability revision stated in physical quantities (e.g. hinge radius, hand span), not keyed to a task; a paired gate admits it only if total successes don't drop, harness-attributed failures don't rise, no cell the bare policy already wins regresses, and zero episodes are contaminated — plus broader regression checks, with revert demonstrated (a candidate that passed the paired gate but lost 79 successes on stove-hob cells in the full round was reverted).

## Key results
- LIBERO-Pro (frozen π0.5, same Qwen3-VL-4B upper model): development block 74.25% vs 20.3% PhyAgentOS and 6.0% Harness VLA; +58.0pp over the frozen policy's 16.2%.
- Post-selection transfer: frozen system scores 75.2% on 800 newly sampled initial states vs 17.5% for the frozen policy; four preregistered snapshots preserve development ranking on new states (Spearman ρ=1.00), dev gain of 14.3 points becomes 14.4 on new states. 261 untouched official states: 77.0% vs 16.5%.
- Execution ablations (same library): full dynamic execution 74.0% vs 63.9% nominal one-step replanning; removing 7 analytic contact skills collapses success 74.0→16.6 (skills supply the competence); recovery/intervention removal only 74.0→73.1.
- A concrete capability update: attribution charged drawer cells to the capability layer; physical-quantity revisions (forearm/hand geometry) raised a drawer cell from 55% to 90% and 100% over 20 seeds, and Goal-suite success 75.25→78.0% over 400 episodes.
- Real hardware: 90% circle pick-and-place, 80% cup stacking, 70% bread pick-and-place, 70% drawer placement (10 trials each, varied object positions). LIBERO-Plus: 84.4% of tasks under seven perturbation categories.

## How it relates to adaptive decomposition
This is the strongest *mechanism analog* in the physical-harness space. The N-layer attribution is a concrete failure localizer: instead of "the harness failed," the system knows *which layer* failed — the same function adaptive decomposition's split logic needs for components. The paired regression gate plus the demonstrated revert (local paired check passed, broader validation failed → revert) is a working instance of revert-when-local-and-global-disagree. Differences are structural: the decomposition is a *fixed* N-layer hierarchy, not agent-discovered splits/fuses; revisions are targeted by attribution but there are no per-component search budgets, no fusing of working components, and no monolithic-fallback for components (substitution happens within-episode at the executor level, not in the evolutionary loop). It's also fully embodied — capabilities are robot skills and a frozen VLA — so the harness being optimized is a physical execution substrate, not an LLM scaffold. Judged as supportive machinery, orthogonal domain, fixed-structure competitor to agent-discovered decomposition.

## Limits and open questions
No explicit limitations section is given; these are derived from the reported numbers. The layer hierarchy is fixed — the agent never discovers new failure layers or restructures the component graph. Unproductive execution remains a problem: 254 of 258 recorded failures ended at ≥99% of budget, failures spend 173 steps after their last progress (51 for successes), and a pilot to cut those suffixes was inconclusive (22 vs 14 wins, p=0.24) — detection and *effective replacement* are called out as separate requirements. In the hardest cells, VLA execution dominates retained failures (91.4% of steps where no cell exceeds 35% success), suggesting analytic-skill coverage is the real ceiling. The paired gate alone is insufficient — one passing candidate still broke five cells, motivating the broader checks. Gains saturate late: the final 1.0-point development increment is uncertain (p=0.0768), and an exploratory learned fast brain (74.1%) matched but did not beat the hand-structured one.
