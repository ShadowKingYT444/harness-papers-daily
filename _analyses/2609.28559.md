## One line
L IDAR: an active black-box fingerprinting method that identifies which LLM is driving a coding agent — not from its text outputs, but from its *behavioral* decisions (whether it verifies edits, recovers from transient failures, resolves spec–test conflicts) under controlled probe pairs.

## The problem
Users increasingly reach LLMs only through opaque remote endpoints (a provider, relay, or compromised router can silently swap in a different model while advertising the same identity). Existing fingerprints infer identity from direct text or token distributions — but a coding-agent harness *mediates* both what the verifier sees (observation mediation: rewriting responses, injecting identity instructions) and what the model does (decision mediation: constructing context, selecting tools, feeding back results). The trajectory is a joint product of model × harness, so a fingerprint built for a direct LLM interface may not transfer. You need identity evidence that survives harness mediation.

## How it works
L IDAR actively probes rather than passively classifying. Three coding-probe pairs each hold the repair objective and repo context fixed while varying *one* condition that exposes a decision: post-edit verification, transient-failure recovery, and specification–test conflict resolution. The resulting trajectories are represented with complementary **instance-level** features (within-pair decisions: tool use, action order, verification, repo outcome) and **distribution-level** features (recurring tendencies across probes and repeated executions). A lightweight, auditable **probabilistic identifier** compares this evidence against frozen, harness-specific enrollment references (clean samples collected once under a declared protocol). Crucially, raw harness labels are excluded from the fingerprint — the method treats the harness as an explicit execution context to control for, not a signal to lean on.

## Key results
- Across 36 models, 7 families, 2 agent harnesses: Top-1 accuracy 95.13% and 88.36% (per harness), MRR 0.9736 and 0.9336.
- Outperforms four existing fingerprinting/API-auditing baselines on all six metric–harness comparisons; robust under representative perturbations.
- The key finding: action sequences carry identity information beyond final outputs, and trajectory organization supplies most of the evidence (no single action dominates).

## How it relates to adaptive decomposition
Tangentially. L IDAR doesn't optimize or decompose harnesses — it's an auditing tool that *treats the harness as a confound to control for*. Its value for this research program is conceptual: it demonstrates that the harness fundamentally reshapes agent behavior (the same model follows different trajectories under different hosts), which is precisely why harness structure is a first-class optimization target. It also shows behavior carries information beyond outputs — relevant if adaptive decomposition ever needs to *detect* which component is misbehaving from trajectories alone. But there is no evolution, no components, no search here.

## Limits and open questions
Closed-set identification only: every query maps to a registered model, so an unknown model gets mislabeled — open-set and mixed-routing cases are explicitly out of scope. An adaptive adversary that knows the probes could tune behavior to evade (GhostPrint-style imitation is cited). Enrollment must be per-harness, so fingerprint coverage scales with the number of harnesses. Open: can the probe design be made adversarially robust, and does the behavioral signal survive when the harness itself is being continuously evolved (the enrollment reference would drift)?
