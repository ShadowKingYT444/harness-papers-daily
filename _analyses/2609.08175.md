## One line
A theoretical framework that answers when a self-modified harness can be safely adopted — deriving a sufficient condition (failure-task gains must outweigh possible retained-task losses plus estimation error) and a two-gate validation rule with high-probability guarantees that adopted updates strictly improve expected reward over the user-task distribution.

## The problem
Harness self-evolution systems (Gödel Agent, DGM, HGM, MOSS) let an agent rewrite its own prompts, code, tools, and orchestration while the underlying LLM stays frozen, and several show big gains on the failed tasks that motivated each change. But a fix that helps on failures can silently degrade tasks the agent previously handled — aggregate improvement is not automatic. The paper asks: under what checkable condition can a self-evolved harness be *reliably adopted*, i.e., guaranteed to raise expected reward over the full user-task distribution, not just the failures it targeted?

## How it works
The setup: at step k the agent is A_k = (M, C_k), a frozen LLM M plus an evolvable harness C_k (prompts, code, tools, orchestration). The agent generates candidate modifications c from failures and interaction history; each yields a candidate agent A_k ⊕ c. Adoption is safe if J_user(A_k ⊕ c) > J_user(A_k), where J_user is expected reward over the user-task distribution D_user.

The core move is decomposing the total expected-reward change into two pieces. A binary failure detector ϕ(t,o) splits the task distribution into an induced failure-task distribution D_F,k and retained-task distribution D_R,k (weighting tasks by the current agent's per-task failure probability ψ and overall failure rate Z_k). Then the overall gain equals the failure-task contribution L_k(c) plus (1 − Z_k) times the mean reward change on retained tasks. A modification is *qualified* if its failure-task contribution L_k(c) ≥ λ and its mean absolute retained-task change D_k(c) ≤ δ. Theorem 1 proves the gain is at least L_k(c) − (1 − Z_k)δ, so Corollary 1: setting λ > (1 − Z_k)δ guarantees strictly positive gain for every qualified modification (choose λ = γ + (1 − Z_k)δ for gain ≥ γ).

Because true quantities are unobservable, the paper gives Rule 1 (Two-Gate validation): adopt c iff the validation-set estimates satisfy L̂_k ≥ τ, D̂_R ≤ δ, and Δ_k := τ − ε_L − (1 − Ẑ_k + ε_Z)(δ + ε_D) > 0, i.e., a positive lower bound on gain after subtracting estimation errors. Theorem 2: the probability of adopting a candidate whose true gain falls below Δ_k is ≤ β_step,k. From there: Theorem 3 bounds the probability that a pool of N generated candidates yields an adoptable one — (1 − β_stat)[1 − (1 − P_k^+)^N] ≤ R ≤ 1 − (1 − P_k)^N, where P_k is the *reachability* (probability generation produces a qualified modification); Theorem 4 shows guaranteed per-step gains Δ_k accumulate across K steps with probability ≥ 1 − β_run even though steps depend on each other.

Two extensions matter. First, the ceiling: Two-Gate treats the full allowed retained-task change δ as a possible loss, so Corollary 2 shows it cannot validate improvement once J_user(A_k) ≥ 1 − (1 − Z_k)δ − ε_Σ. Rule 2 (Measured-margin) replaces the worst-case δ with the candidate's own *measured* retained-task decrease D̂_R^−, validating beyond the original ceiling (Proposition 19 constructs cases where it does). Second, validating small gains near the reward ceiling gets expensive: Theorem 5 proves any level-β validation procedure needs expected cost Ω(Z/u) candidate runs to distinguish a gain of u/2 from a loss of u/2 when remaining gap is u. Section 5 adds a diagnostic: estimate reachability from extra audit data with uniform confidence bounds (Theorem 6) to tell apart "generation rarely produces qualified mods" from "validation lacks evidence" — applied to DS-1000 (see results).

To reimplement the core idea: (1) sample a validation task set; label each task as failure or retained using the current agent's outcomes; (2) run current agent and candidate agent on both groups with repeated runs; (3) estimate failure-task contribution L̂, mean absolute retained-task change D̂, and failure rate Ẑ with confidence bounds (Hoeffding/empirical-Bernstein); (4) adopt iff L̂ ≥ τ, D̂ ≤ δ, and τ − ε_L − (1 − Ẑ + ε_Z)(δ + ε_D) > 0 with τ chosen so the margin exceeds (1 − Ẑ)δ. Refresh reference (retained-task) data after each adoption, since D_R,k is redefined against the new current agent.

## Key results
This is a theory paper; the main results are theorems (conditions, guarantees, ceilings, cost lower bounds), not benchmark numbers. The one empirical illustration is a DS-1000 experiment with persistent Python solver-harness modifications and a fixed LLM: three generation processes each produced 96 outputs in 24 pools (four contexts), evaluated on 56 audit tasks per context at target T_0 = (0.05, 0.50). Independent generation: 38.5% of outputs met the audit target (90% bootstrap CI [0.135, 0.646]) but only 2/96 were validated and 2/24 pools adopted anything. Label-free revision: 26.0% met target, 0/96 validated. Outcome-feedback revision: 34.4% met target, 0/96 validated. Retrospective analysis on one unadopted outcome-feedback candidate gave 95% joint bounds L ≥ 0.0550, D ≤ 0.2766, Δ ≥ 0.0556 on the fixed audit set — its original validation lower bound for L was 0.0378 (below the 0.05 bar), diagnosing *insufficient validation evidence*, not generation failure, as the stall cause. No accuracy/score numbers beyond these fractions are given; all other claims are formal bounds.

## How it relates to adaptive decomposition
The paper does not decompose the harness at all: evolution is monolithic — a candidate modification c rewrites any part of prompts/code/tools/orchestration and is adopted or rejected wholesale as A_k ⊕ c, with a single scalar gate on total retained-task change. There is no splitting into subproblems, no parallel component search, no fusion or fission of components, and no revert-to-monolithic mechanism; the decomposition is absent, not fixed. The action set is evolvable (free-form code/prompt rewrites), which matches adaptive decomposition's spirit of open-ended structural change, but the theory only constrains *adoption*, never the search itself. It is directly complementary: an adaptive-decomposition system could use this two-gate rule as its adoption criterion (λ, δ on failure-gain vs. retained-change, measured per-component or globally) to guarantee that each accepted split/fuse/revert step raises overall expected reward, addressing the exact "local improvement, global regression" risk that decomposition systems face. Relevance 3: central to reliable recursive harness self-improvement, but the mechanism is orthogonal to decomposition itself.

## Limits and open questions
The guarantees hold only under a fixed user-task distribution and fixed reward; distribution drift gets a total-variation correction in the appendix, but it requires bounding drift *before* deployment, which is hard in practice. Reward ≠ user utility: transferring guarantees to utility needs a bounded reward–utility discrepancy. The cost analysis (Theorem 5) shows validating improvements near the ceiling demands ever more evaluation runs, so the theory may stall exactly when gains matter most unless Rule 2-style measurement or smarter budget allocation is used. Open: use the reachability diagnostics to *guide* generation (not just diagnose); characterize when adopted updates preserve future improvement opportunities (flagged as future work); and extend task-group protection (Appendix B.2) to finite-sample estimation guarantees.
