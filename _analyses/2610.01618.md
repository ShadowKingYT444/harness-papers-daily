## One line
More than 18,000 trajectories show that agent configuration and ordinary reruns both have large effects on measured performance.

## The problem
An agent is not only a model. Its information, reasoning setup, verification mechanism, and time budget can change the result.

## How it works
The study varies task information, reasoning, self-verification, time budget, and model choice on four scientific tasks. It examines final outcomes and trajectory behavior.

## Key results
About 54% of outcome variance comes from repeating the same configuration. Task information has the largest measured effect. More time helps only when the system has enough information or model capability. A dedicated verification tool changes verification behavior much more than a request in the prompt.

## How it relates to adaptive decomposition
RHEvolution should not treat a one-run improvement as strong evidence. Candidate comparison needs repeated runs or another uncertainty-aware test. The verification result also supports structural edits: adding a real verification component can matter more than changing prompt text. Interactions between configuration choices mean component effects may not be additive.

## Limits and open questions
The study uses four scientific tasks, so the effect sizes may change on coding benchmarks. It evaluates human-selected configurations rather than automatic structural evolution.
