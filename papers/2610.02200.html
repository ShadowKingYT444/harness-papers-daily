VISTA: A Visual Harness for Reasoning in an Interactive World

Day 76 · Dec 14, 2026

VISTA: A Visual Harness for Reasoning in an Interactive World

Qiushi Han, Keya Hu, Linlu Qiu, Cathy Wu, Kaiming He · published 2026-10-01 · arXiv:2610.02200

highly relevant

One line

VISTA is a visual harness giving a general multimodal model long-horizon vision: the agent perceives rendered images, the harness keeps a lossless visual memory of every frame in original form, and the model actively retrieves and reorganizes its visual input as it reasons — lifting Claude Opus 5.0's ARC-AGI-3 Relative Human Action Efficiency from 40.68 to a perfect 100.00 (all 25 public games, 57.4% fewer actions than first-time humans).

The problem

ARC-AGI-3 agents typically get textual or symbolic environment representations; compressing the world into text (or into the model's context) loses the appearance and spatial relations the reasoning needs, and prior ARC-AGI-3 approaches rely on program synthesis abstractions that get harder as environments grow visually complex. The claim: multimodal models already possess strong reasoning, and the right harness — one that preserves raw visual evidence — unlocks it.

How it works

Three visual harness components. (1) Visual observations: rendered images instead of textual grids. (2) Lossless visual memory: every frame returned by the environment, including intermediate animation frames, stored in original form, indexed by turn and frame number, persisting across the episode. (3) Visual inspection tools: the agent actively requests enlarged views of arbitrary rectangular regions and revisits frames across time, reorganizing its visual input mid-reasoning; automatic per-action frames are reduced (final frame only) so the model inspects on demand rather than drowning in frames. Plus supporting scaffolds: continuous conversation with compaction past context limits, and revisable notes (GUIDE.md, WORKING.md) where the agent builds a compact model of the game. The paper's harness-ladder ablation adds components cumulatively: text grid → 2D image → raised action/time limits → continuous conversation → notes → lossless memory + inspection → pixel readout.

Key results

ARC-AGI-3: Claude Opus 5.0 RHAE 40.68 → 100.00 with VISTA, completing all 25 public games using 57.4% fewer actions than first-time human participants (the official textual-grid implementation scores 13.33). The ladder ablation (on GPT-5.6 Sol) shows cumulative gains at each step, with lossless memory + inspection among the largest jumps. The design extends with minimal adaptation to three additional visual-game/puzzle benchmarks, substantially beating same-model minimal-harness baselines. An early version appeared as a blogpost (vista-research.github.io, Aug 2026).

How it relates to adaptive decomposition

VISTA is a fixed, hand-designed harness — but its lesson is about what a harness is for: preserving raw evidence and letting the model decide what to attend to, rather than pre-compressing the world into the designer's abstraction. That is the same principle adaptive decomposition applies to harness structure: don't fix the abstraction in advance; keep the raw material and let the agent organize it. The lossless-memory discipline also maps onto a concrete need in the user's loop: an evolving harness needs a faithful, uncompressed record of what actually happened (trajectories, tool outputs) to attribute failures correctly — VISTA argues compression is where reasoning dies. The ablation ladder is itself a mini decomposition study: each component's marginal contribution is measured, which is the empirical attitude the user's split/fuse decisions need. The contrast is obvious and useful: VISTA optimizes the observation channel of a fixed harness; adaptive decomposition optimizes the structure of the harness. Both say the same thing: the model is stronger than the scaffolding usually lets it be.

Limits and open questions

Stated by the authors: the models used were released after the public ARC-AGI-3 games, so training contamination cannot be ruled out — the private set would be the real test. The harness ladder is measured on one model (GPT-5.6 Sol) while the headline number is another (Claude Opus 5.0). The three additional benchmarks are visual games/puzzles in the same family; real-world visual environments (GUI, robotics) are future work. And the "minimal adaptation" claim for new environments is asserted more than measured.
