CAVEAT: Towards Robust Computer-Use Agents in Incentive-Misaligned Environments

Day 27 · Oct 26, 2026

CAVEAT: Towards Robust Computer-Use Agents in Incentive-Misaligned Environments

Yuxuan Li, Will Epperson, Wesley Deng, Zezhou Huang · published 2026-09-23 · arXiv:2609.27273

context

One line

A benchmark for whether computer-use agents still buy the user-optimal product when a marketplace's own incentives (sponsored placement, drip pricing, scarcity cues) steer them — plus a fixed two-step harness that pins down the objective before browsing and verifies the decision before buying.

The problem

Existing agent benchmarks test task completion in neutral environments or explicit attacks, but not the common middle case: a platform operating exactly as designed while its own incentives (ads, ranking, pricing tricks) conflict with the user's goal. The authors formalize "incentive-misaligned environments" and ask whether agents preserve the user's objective there. A computer-use agent that correctly buys the best laptop in a clean store might buy a worse one when sponsored placements and urgency badges appear — the task didn't change, only the choice architecture.

How it works

CAVEAT is nine browser-based marketplaces (retail, lodging, grocery, resale, etc.) with an eight-family steering taxonomy: sponsored placement, preferential ranking, drip pricing, promotional framing, defaults & bundling, scarcity & social proof, trust signals, friction & obstruction. Each task has exactly one user-optimal product (validated programmatically against the catalog). Every task is evaluated twice: a matched control with all steering disabled and an incentive-misaligned condition with all eight enabled — the request, catalog, prices, and optimal product are identical, so the gap Δ = R(control) − R(misaligned) isolates incentive-induced degradation. Trajectory analysis of failures found three decision weaknesses: (1) premature search closure (agents stop after seeing surfaced options), (2) imposing unstated priorities during comparison, (3) committing before resolving decision-relevant facts like full price. The authors then hand-designed CAVEAT-Harness from this diagnosis: the agent must explicitly pin down the user's objective before browsing, and verify its decision before buying. They also post-train a smaller model on trajectories that follow this process.

Key results

  • Across 18 model configurations on CAVEAT-Standard: optimal purchase rate drops from 78.6% (control) to 17.3% (steering on).
  • On CAVEAT-Hard (2,112 products/task): GPT-5.6-Sol-high drops from 90.0% to 0.0%.
  • CAVEAT-Harness: GPT-5.6-Terra goes 11.7% → 66.7% (Standard subset); GPT-5.6-Sol goes 0.0% → 80.0% (Hard).
  • Weaker models gain little: Qwen3.5-27B reaches only 4.2% with the harness; post-training it (CAVEAT-27B) lifts it to 22.9% — so the harness depends on the model being able to execute the prescribed decision process.

How it relates to adaptive decomposition

Not at all structurally. CAVEAT-Harness is a fixed, human-designed two-step procedure derived from diagnosing failures — the decomposition of the decision process (define objective → browse → verify) is fixed by the researchers, not discovered by the agent. Nothing is evolved, split, fused, or given independent search budgets. It is useful as a contrast case: it shows how much a fixed hand-designed harness can buy, which makes the argument for adaptive decomposition sharper — if the decomposition granularity were itself evolvable, you wouldn't need humans to do the trajectory analysis and hand-code the fix.

Limits and open questions

The mitigation is inference-time only and brittle: it works only if the model can carry out the prescribed process (small models mostly can't), and the harness itself never adapts. The benchmark covers marketplaces only — does the same failure pattern hold in tooling/API environments where incentives aren't visual? Open: whether the three failure modes can be detected online by the agent itself and countered with a self-generated procedure rather than a human-designed one.
