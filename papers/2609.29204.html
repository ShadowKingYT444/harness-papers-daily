AdaHVLA: Adaptive Harnesses for Long-Horizon Vision-Language-Action Execution

Day 17 · Oct 16, 2026

AdaHVLA: Adaptive Harnesses for Long-Horizon Vision-Language-Action Execution

Junyi Tang, Jie Peng, Zezhen Ding, Yuan Shen, Tianlong Chen · published 2026-09-24 · arXiv:2609.29204

relevant

One line

Adapts the code-based coordination policy between a high-level agent and a VLA executor through robot experience, using a multiagent evidence→hypothesis→revision loop and a revision graph that links every change to its predicted and observed effects.

The problem

VLAs are good at local control and instruction following but bad at long-horizon execution: the robot must retain relevant history, track what remains, and adjust when execution departs from the plan. Skill selection alone doesn't determine what history to keep, when to advance a task stage, or how to sustain corrective guidance (arriving at a doorway ≠ passing through it). And a plausible-looking code revision to the coordination rules need not produce its intended behavioral effect — code validity alone is an insufficient measure of improvement in closed-loop embodied execution.

How it works

The harness is an editable code-based coordination policy deciding: which observations/history the VLA receives, when to advance a task stage, how to respond to deviations, and when the task is complete. Between robot rollouts, a multiagent adaptation process with three distinct working contexts runs: (1) evidence analysis — examine execution traces; (2) harness revision — propose a code change guided by a testable coordination hypothesis (which mechanism should change + what behavior should follow); (3) behavioral assessment — subsequent rollouts test the predicted effects. A revision graph links execution evidence → hypotheses → revisions → observed effects, preserving alternative harnesses and adaptation memory so failed attempts still inform candidate selection, within a task and across tasks/environments. Adaptation thus validates behavior, not just code.

Key results

  • NaVILA-LH (quadruped navigation): mean test success rises from 22.5% (initial harness) to 31.7–57.5% depending on model.
  • Manipulation: up to +30.8 percentage points over the initial harness across three VLA backbones, on both long-horizon levels.
  • Real-world deployment shows stable execution across task stages.

How it relates to adaptive decomposition

AdaHVLA is adaptive-harness work with a nice structural artifact (the revision graph preserving alternatives), but the decomposition is fixed: task stages and the policy's coordination dimensions are set by the human designers, and revision mutates the whole coordination policy as one unit. There is no agent-discovered decomposition, no independent search budgets per component, no splitting failing stages or fusing working ones. The revision graph is interesting as a memory of the search process — adaptive decomposition could use something similar to track component lineage — but AdaHVLA lacks any change to decomposition granularity itself.

Limits and open questions

Revision quality depends entirely on the hypothesis-generation agent; bad hypotheses waste robot rollouts, which are expensive. The paper doesn't say how much adaptation budget is needed per task, or whether a revision that works on one layout breaks another (the graph preserves alternatives but doesn't resolve conflicts). Open: can hypothesis formation itself be made self-supervised (compare RHO's self-validation), and does the revision graph grow unmanageably over long deployment lifetimes?
